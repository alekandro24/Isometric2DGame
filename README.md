# Isometric2DGame
Unity project as part of the Runic Dice Entertainment trial.  
  
The objective of the project is to implement multiple tasks while maintaining a clean coding structure and following good version control workflows.

## Installation
Clone the repository and fetch the code into your existing Unity project workspace.

## Controls
| Action | Keybinding |
| :--- | :--- |
| **Movement** | `W`, `A`, `S`, `D` or **Arrow Keys** |
