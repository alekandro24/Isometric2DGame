# Isometric2DGame

A 2D isometric game developed in Unity as part of the **Runic Dice Entertainment programming trial**.

The project focuses on implementing the required gameplay features while maintaining a clean, modular codebase and following good development and version control practices.

## Project Overview

The project includes the following features:

- **Player Movement:** 2D movement using the Unity Input System.
- **Enemy AI:** State-based enemy behaviour, including patrolling, chasing, and attacking.
- **Inventory System:** Item collection, inventory management, and item usage.
- **Pathfinding:** Navigation around environmental obstacles using the A* Pathfinding Project.

## Getting Started

### Requirements

- [Unity 6](https://unity.com/releases/editor/whats-new/6000.4.1) — version `6000.4.1f1`
- Git

### Installation

1. Clone this repository:

   ```bash
   git clone <repository-url>
   ```

2. Open Unity Hub.
3. Select **Add project from disk**.
4. Select the cloned `Isometric2DGame` folder.
5. Open the project using the required Unity version.

## Controls

| Action | Keybinding |
| :--- | :--- |
| **Movement** | `W`, `A`, `S`, `D` or Arrow Keys |
| **Interact / Pick Up Item** | `E` |
| **Toggle Inventory** | `I` |
| **Use Item** | Double Left Click on an inventory item |

## AI Usage

AI tools were used as a supplementary resource during development, primarily for:

AI assistance was used for research, explanations, and technical guidance. The project implementation, code integration, testing, and final decisions were carried out by the developer.
